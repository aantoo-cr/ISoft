Participante

Si deseas participar en una hackatón, este es el tipo de cuenta que necesitas crear. Obtendrás acceso inmediato a tu perfil y podrás comenzar a participar sin necesidad de validación por parte de un administrador.

Organización

Si eres el representante de una organización y deseas registrarla en la plataforma, esta es la cuenta adecuada para ti. El acceso será otorgado una vez que un administrador verifique la validez de los datos de la organización.
